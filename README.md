# games-of-42
Games of 42 is a real-time moderated challenge engine for live, structured play inside the H2GE Guides ecosystem. It combines a Player App and a GameRunner Console with AI-assisted safety checks, live session control, and 42-based constraints on timing, scoring, and participation. Specification and architecture in progress.


It consists of two primary components:

1. Player Application (integrated within H2GE Guides)
2. GameRunner Console (live session control system)

The system is built around structured, real-time challenge creation and moderation with safety-first AI evaluation.

---

## Core Principles

- Live moderated sessions
- Real-time challenge workflow
- AI-assisted safety screening
- Structured 42-based game constraints
- Buildable architecture

---

## Platform Components

### Player Application
- Join and participate in live sessions
- Propose challenges
- Communicate with GameRunner
- Track progress and completion

### GameRunner Console
- Launch and control sessions
- Approve and modify challenges
- Monitor players
- Broadcast communications
- Override AI safety checks

## Technical Status

Current stage: Specification Phase



---

## Why 42?

42 is the default structural constraint across sessions:
- 42 minute sessions
- Up to 42 players
- 42-point challenge system

The number is configurable but defaulted.
